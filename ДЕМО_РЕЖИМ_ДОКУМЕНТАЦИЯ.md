# Система демо-режима и лицензирования HybridCache

## Обзор

HybridCache теперь поддерживает комплексную систему лицензирования с демо-режимом, которая позволяет:

- **Демо-режим** - ограниченная функциональность на 30 дней
- **Полная лицензия** - полный доступ ко всем функциям
- **Гибкие ограничения** - настраиваемые лимиты для разных типов лицензий

## Компоненты системы

### 1. `demo_license_system.py`
Основная система управления лицензиями:
- Генерация и проверка лицензий
- Отслеживание использования
- Проверка ограничений
- Активация полных лицензий

### 2. `commercial_service_licensed.py`
Модифицированный коммерческий сервис с интеграцией лицензий:
- Проверка лицензий перед каждой операцией
- Ограничения на основе типа лицензии
- API для управления лицензиями

### 3. `demo_license_test.py`
Демонстрационный скрипт для тестирования системы лицензий

## Типы лицензий

### Демо-лицензия (Demo License)
```json
{
  "license_type": "demo",
  "expires_at": "2024-02-15T10:30:00",
  "max_files": 100,
  "max_cache_size_mb": 1024,
  "max_requests_per_hour": 1000,
  "features": ["basic_caching", "aes_encryption"]
}
```

**Ограничения:**
- ✅ 30 дней использования
- ✅ До 100 файлов
- ✅ До 1GB кэша
- ✅ 1000 запросов в час
- ✅ Базовое кэширование
- ✅ AES шифрование
- ❌ GOST шифрование
- ❌ Расширенная аналитика
- ❌ API доступ

### Полная лицензия (Full License)
```json
{
  "license_type": "full",
  "expires_at": "2025-01-15T10:30:00",
  "max_files": 1000000,
  "max_cache_size_mb": 1000000,
  "max_requests_per_hour": 1000000,
  "features": [
    "basic_caching", 
    "aes_encryption", 
    "gost_encryption", 
    "advanced_analytics", 
    "api_access"
  ]
}
```

**Возможности:**
- ✅ 1 год использования
- ✅ Практически без ограничений на файлы
- ✅ До 1TB кэша
- ✅ Неограниченные запросы
- ✅ Все функции включены

## API для управления лицензиями

### Получение информации о лицензии
```http
GET /api/license
```

**Ответ:**
```json
{
  "license_type": "demo",
  "status": "active",
  "status_message": "Demo license active (25 days remaining)",
  "expires_at": "2024-02-15T10:30:00",
  "max_files": 100,
  "max_cache_size_mb": 1024,
  "max_requests_per_hour": 1000,
  "features": ["basic_caching", "aes_encryption"],
  "customer_id": "demo_user",
  "usage_stats": {
    "files_processed": 45,
    "requests_made": 234,
    "cache_size_bytes": 524288000
  }
}
```

### Активация полной лицензии
```http
POST /api/license/activate
Content-Type: application/json

{
  "license_key": "ABCD1234EFGH5678IJKL9012MNOP3456"
}
```

**Ответ:**
```json
{
  "status": "success",
  "message": "Full license activated successfully"
}
```

### Получение статистики использования
```http
GET /api/stats
```

**Ответ:**
```json
{
  "cache_stats": {
    "file_count": 45,
    "total_size_bytes": 524288000,
    "total_size_mb": 500,
    "files": ["test1.txt", "test2.bin", ...]
  },
  "license_info": {
    "license_type": "demo",
    "status": "active",
    "max_files": 100,
    "usage_stats": {
      "files_processed": 45,
      "requests_made": 234
    }
  },
  "timestamp": 1705123456.789
}
```

## Коды ошибок лицензий

| Код | Описание | Действие |
|-----|----------|----------|
| 402 | License limit exceeded | Превышены лимиты лицензии |
| 402 | License expired | Истек срок действия лицензии |
| 402 | Feature requires full license | Функция требует полную лицензию |
| 429 | Request limit exceeded | Превышен лимит запросов |

## Установка и запуск

### 1. Установка зависимостей
```bash
pip install fastapi uvicorn cryptography requests
```

### 2. Запуск сервиса с лицензиями
```bash
# Настройка переменных окружения
export HYBRIDCACHE_DIR="/path/to/cache"
export HYBRIDCACHE_SOURCE="/path/to/source"
export HYBRIDCACHE_ENCRYPTION="0"  # Отключить шифрование для демо

# Запуск сервиса
python commercial_service_licensed.py --host 0.0.0.0 --port 8081
```

### 3. Тестирование системы лицензий
```bash
python demo_license_test.py
```

## Конфигурация демо-режима

### Переменные окружения
```bash
# Основные настройки
HYBRIDCACHE_DIR="/cache"              # Директория кэша
HYBRIDCACHE_SOURCE="/source"          # Исходная директория
HYBRIDCACHE_ENCRYPTION="0"            # Шифрование (0/1)

# Настройки лицензий (опционально)
HYBRIDCACHE_MASTER_KEY="your_key"     # Мастер-ключ для подписи лицензий
```

### Файлы лицензий
- `hybridcache.license` - файл лицензии
- `usage_stats.json` - статистика использования

## Бизнес-модель

### Монетизация
1. **Демо-период** - 30 дней бесплатного использования с ограничениями
2. **Платный переход** - активация полной лицензии по ключу
3. **Подписка** - ежегодное продление лицензии

### Ограничения демо-режима
- **Файлы**: 100 файлов (достаточно для тестирования)
- **Кэш**: 1GB (подходит для небольших проектов)
- **Запросы**: 1000/час (достаточно для разработки)
- **Функции**: базовые (AES, кэширование)

### Преимущества полной лицензии
- **Масштабируемость**: до 1M файлов, 1TB кэша
- **Производительность**: неограниченные запросы
- **Безопасность**: GOST шифрование
- **Аналитика**: расширенная статистика
- **Поддержка**: приоритетная техническая поддержка

## Интеграция с существующими сервисами

### Совместимость
Система лицензий полностью совместима с существующими сервисами:
- `gov_service.py` - может быть дополнен системой лицензий
- `commercial_service.py` - базовая версия без ограничений
- `commercial_service_fast.py` - оптимизированная версия

### Миграция
Для добавления лицензий к существующему сервису:
1. Импортируйте `demo_license_system`
2. Добавьте проверки лицензий в критические функции
3. Обновите API endpoints
4. Настройте ограничения

## Безопасность

### Защита лицензий
- **Цифровая подпись** - все лицензии подписаны мастер-ключом
- **Проверка целостности** - валидация подписи при загрузке
- **Шифрование** - лицензии могут быть зашифрованы
- **Привязка к системе** - опциональная привязка к hardware ID

### Защита от обхода
- **Серверная проверка** - в продакшене проверка на сервере лицензий
- **Периодическая валидация** - регулярная проверка статуса лицензии
- **Логирование** - отслеживание попыток обхода ограничений
