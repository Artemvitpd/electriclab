** Промт для запуска и тестирования:** Требуется **локальное тестирование** двух версий ** HybridCache **: 1. `hybridcache_enterprise_v2.3_final.py` (для госсектора, с КриптоПро CSP) 2. `hybridcache_standard_v2.1_final.py` (для коммерческого сектора, с AES/ pygost ) **Шаги:** 1. **Подготовка окружения**: - Создать виртуальное окружение Python 3.9+. - Установить зависимости: - Для ** Standard **: ` pip install -r requirements_standard.txt` - Для ** Enterprise **: ` pip install -r requirements_enterprise.txt` - Если `requirements_enterprise.txt` нет — установить: ` pip install cryptography pywin32` (на Windows ). - Для ** Enterprise **: Убедиться, что ** КриптоПро CSP 5.0+** установлен (иначе тесты шифрования упадут). 2. **Запуск тестов**: - **Для Standard **: - Установить переменную окружения: ` export HYBRIDCACHE_SECRET_KEY=$( python -c " import base64; import os ; print (base64.b64encode( os.urandom (32)). decode ())")` - Запустить: ` python hybridcache_standard_v2.1_final.py -- mode office -- preload " test_file.xlsx "` - Проверить: создание кэша в `C:/HybridCache` (или другой путь), шифрование (если включено). - Запустить API: ` python hybridcache_standard_v2.1_final.py -- run-server -- enc-mode aes ` (или ` gost `, если ` pygost ` установлен). - Проверить: ` curl http://127.0.0.1:8090/api/cache/test_file.xlsx` (если файл был закэширован ). - **Для Enterprise **: - Установить переменную: ` export HYBRIDCACHE_GOST_CONTAINER=" HybridCache_GOST "` - Убедиться, что контейнер ` HybridCache_GOST ` существует в КриптоПро CSP. - Запустить: ` python hybridcache_enterprise_v2.3_final.py -- mode office -- preload " test_file.xlsx "` - Проверить: создание кэша, `.sha256` файлов, запись в ` hybridcache_security.log `. - Запустить API (если включён в версию): ` python hybridcache_enterprise_v2.3_final.py -- run-server `. - Проверить: ` curl http://127.0.0.1:8090/api/cache/test_file.xlsx`. 3. **Проверка функций**: - Режимы: ` office `, ` media `, ` game ` — должны корректно прогружать файлы. - Автосохранение : `-- autosave-test ` — должен создать файл. - Шифрование: включить `-- enc-mode gost ` или AES, проверить, что файлы в кэше зашифрованы. - Целостность (только Enterprise ): проверить, что `.sha256` файлы создаются и проверяются. - Очистка: `-- clear-expired ` (если есть) — должен удалять старые файлы. 4. **Анализ результатов**: - Успешный запуск без ошибок. - Файлы появляются в кэше. - Шифрование/дешифрование работает (если включено). - Целостность проверяется (только Enterprise ). - API отвечает корректно (если запускался). **Цель**: - Подтвердить работоспособность обеих версий. - Выявить ошибки при отсутствии КриптоПро /` pygost `. - Проверить производительность кэширования и очистки. **Результат**: - Вывод команд и логи . - Ошибки (если есть). - Время выполнения операций (приблизительно).
